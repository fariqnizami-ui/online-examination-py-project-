# Online Examination System

## Project Description
The Online Examination System is a simple GUI-based application developed using Python and Tkinter.

It allows students to enter their names, answer multiple-choice questions, and view their final scores.

## Features
- Student name input
- Multiple-choice questions
- Four options for each question
- Automatic answer checking
- Score calculation
- Final result display
- User-friendly graphical interface

## Technologies Used
- Python
- Tkinter

## Concepts Used
- Python Lists
- Nested Lists
- Functions
- Global Variables
- If-Else Statements
- While Loop
- Tkinter GUI Widgets
- RadioButtons
- Entry and Label Widgets

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python online_exam.py
```
